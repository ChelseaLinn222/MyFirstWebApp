What I Have Learned

While creating this web application, I have learned how HTML elements are used to structure a webpage. I have also learned that attributes provide additional information about HTML elements.

For example, the image uses the src attribute to tell the webpage where the image is located. The alt attribute provides a description of the image, which can be useful for accessibility.
