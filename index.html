About CJ Bakes

CJ Bakes is a baking website showcasing a selection of cakes created for birthdays and special occasions.

This website will be developed further throughout the module as new web development technologies and techniques are introduced.

Baking Tips

Good preparation can make baking easier and help produce better results.

  • Measure your ingredients carefully.
  • Preheat the oven before you start baking.
  • Read the recipe before you begin.
  • Allow cakes to cool before decorating them.

Accessibility

Semantic HTML elements have been used to give the webpage a clear structure.

Alternative text has been provided for each cake image to help users who rely on screen readers.

Colours have been chosen to provide clear contrast between text and backgrounds. The navigation links and button can also be accessed using the keyboard.
