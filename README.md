# CJ Bakes – Web Technologies Project

# Files

- `index.html` – this is the main structure of the website.
- `css/style.css` – the styling, responsive layout and additional animations.
- `js/script.js` – the JavaScript for interactive features, form validation, confetti and recipe API calls.
- `EightCake.jpeg`, `SevenCake.jpeg`, `SixtyCake.jpeg` – the cake photos used on the website. These are saved in the main folder along with the index.html.

# Features

- Responsive layout using Bootstrap 5 and Bootstrap Icons https://www.w3schools.com/bootstrap5/
- Navigation bar, cake gallery, About section and baking tips  https://www.w3schools.com/css/css_navbar.asp
- Accessibility features, including alt text, keyboard focus styles and reduced-motion support https://www.w3schools.com/css/css_accessibility.asp 
- Cake enquiry form with required fields, date validation, a character counter and an enquiry preview. https://www.w3schools.com/js/js_validation.asp 
- Confetti animation when an enquiry preview is created, with reduced-motion support.
- Recipe ideas from TheMealDB, including random desserts, recipe details and ingredient searches.
- Loading messages and error handling for recipe searches.

# Running the website

You can open `index.html` in your browser while connected to the internet. 

# A quick note about the form

The cake enquiry form only creates a preview of the details entered. It doesn't send personal information, email CJ Bakes or make an actual booking.
